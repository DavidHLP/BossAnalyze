## 数据与验证边界

保留现有业务数据、进程与凭据。新增约束先提供存量审计与保留数据的增量路径，不运行现有库迁移。排除项保持排除；运行数据、浏览器、并发和部署条件相关结论单独记录，不能用静态检查冒充验收。

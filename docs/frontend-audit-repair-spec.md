# 前端业务与体验审查修复规格

来源：#24（合并审查报告，基线 `440d8b658f9aba1309b752a9a4b8512c72a88abc`）。
目标：在一个修复 PR 中落实报告中已确认且合理的问题，保留 API 路径、现有数据、账户与服务。

## 任务图

A、B、C 可独立实现；D 汇总依赖 A+B+C；E 验证与双轴审查依赖 D。
每个实现任务在自己的 worktree/分支提交，由汇总任务合入主修复分支。

### A：服务端访问控制与角色语义

- 管理读取/写入按现有权限标识授权，不能仅判断已登录或硬编码所有操作只能 ADMIN。审查全部现有调用者，保留普通用户读取自身账户/角色/权限及菜单的能力。
- 日志统计、健康和分析触发移出匿名公开前缀；统计权限与前端看板一致，触发单独写权限，健康只返回必要脱敏状态。
- 招聘同源路径通过认证网关访问分析服务；保留前端 URL。拒绝无效/停用角色的访问，及时处理缓存，不能仅在首次登录检查。
- 同名角色创建/改名在服务端拒绝，默认 USER 身份唯一；不得自动变更/去重现有数据。新库 SQL 可增加约束，现库使用安全的说明/显式迁移方案，不导入 drop-table 快照。
- 移除或迁至服务端的公共 Upstash 私有令牌路径；不得读取/打印真实值。
- 加入必要的隔离权限/认证回归，证明匿名 401、普通账户无权 403、合法权限正常；覆盖停用角色和重名角色。

所有权：backend/api、database 的必要非破坏性说明/约束、frontend/nuxt.config.ts、frontend/server、frontend/app/api/modules/resume.ts、对应测试。
不修改招聘计算 Java、散点组件或会话/导航 UI。

### B：前端会话、菜单语义与恢复体验

- 退出前先解决未保存内容；取消离开必须同时保留 token 与表单。覆盖用户/角色/菜单编辑者及自我授权导致的退出。
- 临时恢复请求失败不能清除有效 token；保持权限失败闭合，提供明确错误和重试，不借此绕过守卫。
- 缺少 token 和中途 401 使用统一安全回跳，恢复原 fullPath；不要声称路由回跳能恢复内存草稿。
- 区分授权菜单树与导航可见性；隐藏入口仍可授权直达，整个隐藏节点保留原移除语义。
- 后端菜单图标接入现有图标机制；未实现的重定向/缓存/始终显示元数据明确标识不在当前控制台生效，不引入动态执行代码或虚构设置。
- 布局加跳过导航与可访问主内容目标，并妥善处理路由变化焦点。
- 看板至少区分 403 与可重试服务故障；使用现有错误分类模式。
- 核实并统一工作台/看板时间显示及快照口径；占位页清楚说明功能未开放和现有返回动作，无虚构排期。
- 扩展相关现有测试验证恢复、回跳、导航与未保存退出，运行 frontend 测试/类型检查/构建。

所有权：frontend 中除 A 所有文件及 C 散点组件以外的会话、导航、菜单、布局、页面、辅助函数与相关测试。
保持招聘数据页面与 C 的契约兼容。

### C：招聘计算与图表可访问性

- 薪资区间中点使用小数，贯通 UDF、数值模型、序列化、调用方；4-5K 应为 4.5K。
- 未知/空学历和经验不能映射为不限；保留 null 并由有效维度过滤，不把未知计入有效样本。
- 散点分组数量有键盘和触控可达的等价文本/列表，含抽样时全部分组的语义。避免无意义大表撑爆页面，复用现有组件。
- 适当提高标记可辨性，不声称未测对比度合规。
- 必要的隔离计算回归，覆盖奇数区间、未知值和不限；不运行真实分析任务。

所有权：backend/analytics 招聘计算及模型与对应测试，frontend/app/components/recruitment/ScatterPlot.vue（必要的纯函数及其测试需先告知汇总者，避免 B 冲突）。
不改 API 授权网关、nuxt.config、会话或其他页面。

## 不实施或条件性处理

- 不因未经验证的 5 秒耗时风险直接调大超时，不把严格解析改成静默跳过坏记录。
- 不新增简历 UI、公司列表、三维分析、设置/个人中心保存能力。
- 不迁移、seed、改写既有业务数据，不停服务，不泄露配置值。
- 浏览器与真实数据验收分开报告；源码/单测通过不冒充运行验收。

## 验证与交付

- A/B/C 提交均含项目要求 Signed-off-by；单一修复分支、草稿 PR。
- 汇总后执行前端测试、类型检查、构建，以及 backend reactor 与 credential contract 必要检查。
- 完成 standards/spec 两轴代码审查，修复所有确认问题后标记 PR ready。
- UI 验证使用隔离夹具，不写真实账户；环境不足如实列出。
- 按 implement-spec 本次交付为 ready-for-review PR，不自动合并或部署。
